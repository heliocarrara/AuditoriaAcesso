# CARGO: DESENVOLVEDOR

Desenvolver sistemas e aplicações, utilizando linguagem de programação, conforme especificações do projeto; planejar e realizar modelagem básica de estrutura de banco de dados; codificar, testar e implantar programas de computador; realizar manutenção de sistemas e aplicações, alterando o processamento, codificação e demais elementos, com o objetivo de corrigir falhas e atender alterações ou novas necessidades.

## DESCRIÇÃO DETALHADA

- Desenvolver sistemas e aplicações, utilizando as linguagens de programações que mais se aplicarem ao projeto;
- Elaborar a modelagem básica de estrutura do banco de dados;
- Planejar, codificar, testar e implantar programas de computador;
- Realizar a manutenção de sistemas e aplicações desenvolvidas;
- Participar no levantamento de requisitos, prototipação e documentação de projeto de programas de computador;
- Executar outras atividades correlatas.

### Júnior:

- Desenvolver funcionalidades de baixa a média complexidade em C# / .NET e ASP.NET;
- Realizar manutenção e evolução de sistemas existentes no stack Microsoft;
- Implementar interfaces web com HTML5, CSS3 e JavaScript vanilla ou Vue.js/React;
- Escrever e manter queries SQL no Microsoft SQL Server;
- Seguir padrões de codificação, convenções de nomenclatura e revisões de código;
- Utilizar Git e SVN para controle de versão, respeitando branches e merge policies;
- Registrar e acompanhar tarefas em ferramentas de gestão de projetos;
- Apresentar domínio em:
  - C#
  - .NET / .NET Framework
  - ASP.NET MVC ou Web API
  - HTML5 / CSS3 / JS
  - Vue.js ou React (básico)
  - MSSQL
  - Git / SVN
  - Visual Studio
  - IIS (configuração básica).

## ESPECIFICAÇÕES:

1. **Escolaridade**: Graduação em Sistemas de Informação, Ciências da Computação, Engenharia da Computação e áreas afins. Desejável Pós-Graduação em Tecnologia da Informação.
2. **Experiência**: Desejável experiência de 06 (seis) meses comprovada através de registro em carteira, com vivência comprovada em desenvolvimento de software, conhecimento dos fundamentos de orientação a objetos em .NET e SQL Server, conhecimento sólido em ao menos um framework front-end (Vue.js ou React), domínio do ecossistema Microsoft, conhecimento em testes automatizados e qualidade de software.
3. **Habilidades/Aptidões**: Discrição, capacidade de planejamento e senso de organização, competência técnica e interpessoal, dinamismo, atenção, percepção visual, objetividade, flexibilidade, iniciativa, raciocínio lógico.
